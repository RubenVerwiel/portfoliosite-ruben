# Portfolio — Ruben Verwiel

Persoonlijke portfolio-website. Commerciële Economie & AI.

## Opzet

- `index.html` — de volledige site (HTML, CSS en JS in één bestand)
- `assets/` — profielfoto (`ruben.jpg`), cv (`cv-ruben-verwiel.pdf`) en projectafbeeldingen

## Lokaal bekijken

Open `index.html` in je browser, of draai een lokale server:

```
python3 -m http.server 8000
```

## Live zetten

De site is statisch en heeft geen build-stap. Vercel pakt `index.html` in de root automatisch op; elke push naar `main` gaat vanzelf live.
